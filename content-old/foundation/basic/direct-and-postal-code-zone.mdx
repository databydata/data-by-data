---
title: "What is the difference between a direct zone and a postal code zone?"
category: "Basics"
---

## Direct Zone:
Direct zone is created by adding all locations manually in the list.  

If new vendor is added in the zone, manual update is required to include the location in the zone.  

This is best for grouping specific, non-geographic entities.

### Example **(Specific Relationships):**
You have a **"Milk Run"** where a truck loops around to pick up parts from 5 specific high-priority suppliers every morning.  

If new supplier is to be added, you have to include them in list in zone.


## Postal Code Zone:
This is used to define geographic rule **(All location in zip 1XXX - 1YYY)**.  

Any location falling this zip is automatically considered part of the zone.  

This is best for general distribution planning because it requires zero maintenance when new customers are created.

### Example **(General Distribution)**
You are a retailer shipping standard orders to customers in South Delhi.  

You have thousands of customers in South Delhi, and new ones sign up every day. You cannot manually add every new customer to a zone.  

Furthermore, you create a zone with postal code range and any new customer signing up will automatically considered a part of Delhi zone.


## Additional, Region Zone:
A Region Zone is used when you need to define transportation rules based on broad administrative boundaries (like a Country, State, or Province) rather than specific postal codes.  

Example: Region Goa, India.
